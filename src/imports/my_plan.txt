# osudz.ppy — Community Beatmap Challenge Platform

## 1. PROJECT OVERVIEW

osudz.ppy is a community website for Algerian osu! players.

The website allows eligible Algerian osu! players to:

- discover osu! beatmaps
- save beatmaps as favorites
- submit beatmaps for the monthly community challenge
- select challenge requirements for submitted beatmaps
- vote for submitted beatmaps
- discuss submitted beatmaps
- participate in the winning beatmap challenge
- see their challenge ranking
- see qualifying and non-qualifying scores
- see previous monthly winners

The community votes to select one beatmap as the monthly challenge.

The website automatically progresses through the monthly round phases.

The three main phases are:

1. Submission Phase
2. Voting Phase
3. Challenge Phase

An administrator controls the round, eligibility rules, challenge requirements, durations, exceptions, and site configuration.

# 4. ROUND SYSTEM

Every monthly round has three phases.

## Phase 1 — SUBMISSION

Players submit beatmaps.

Users can:

- browse their website favorites
- import/load favorites from their osu! profile
- submit a beatmap
- select challenge requirements

The dashboard should adapt to this phase.

---

## Phase 2 — VOTING

Players vote for submitted beatmaps.

The dashboard should show:

- whether the current user has voted
- their selected vote
- current leading beatmap
- their submitted beatmaps
- vote counts for their submissions

The voting page displays all submitted beatmaps.

The current leading beatmap should have strong visual emphasis.

---

## Phase 3 — CHALLENGE

Voting closes automatically.

The beatmap with the most votes becomes the monthly challenge.

The dashboard changes into the challenge dashboard.

It displays:

- winning beatmap
- challenge requirements
- challenge countdown
- leaderboard
- player's own ranking
- qualifying scores
- non-qualifying scores
- challenge progress

At the end of the challenge phase:

- qualifying players are determined
- the winner receives the bounty
- the round is archived

The bounty is:

ONE MONTH OF OSU!SUPPORTER
